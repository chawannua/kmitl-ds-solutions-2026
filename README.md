## Usage

Each file is a standalone program that reads one line from standard input, exactly like the grader.

```bash
python Chapter_10_Searching_Hashing/item_5_goods_box.py
# Enter Input : 6 2 4 3 7/3
# Minimum weigth for 3 box(es) = 8
```

## File layout

Every solution follows the same structure:

1. **Header** — problem statement, input and output format.
2. **Solution** — commented Python code.
3. **How it works** — step-by-step explanation with a worked example.
